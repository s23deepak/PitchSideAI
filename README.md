# PitchAI — AI Football Broadcast Companion

> Real-time AI commentary notes, tactical vision Q&A, and Fan Lens broadcast mode for football matches.

Built for the **AMD Developer Hackathon (May 2026)**. PitchAI gives fans and commentators a Peter Drury-style AI co-pilot — pre-match research notes generated by a 7-agent pipeline, live tactical Q&A powered by vision models, and a cinematic Fan Lens overlay with voice interaction.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

---

## What it does

**For fans (Fan Lens mode):** Full-screen video with a scoreboard overlay, trivia cards that surface automatically on key events, and a hold-to-ask mic button for voice Q&A. Ask "How many Clasico goals has Lewandowski scored?" and get a split-screen answer in under 3 seconds.

**For commentators (Dashboard mode):** A teleprompter populated with pre-computed narrative beats, color-coded by confidence. Beats highlight in real-time as vision detects matching events on the pitch.

**For preparation (Notes Hub):** Enter two teams, click Generate. A 7-agent pipeline runs player research, team form analysis, head-to-head history, weather context, and current news in parallel, then synthesizes everything into structured commentary notes in the Peter Drury style.

## Quick Start

```bash
git clone https://github.com/your-username/PitchAI.git
cd PitchAI

# Backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # set LLM_BACKEND=ollama at minimum

# Pull models (Ollama)
ollama pull qwen2.5:3b
ollama pull qwen2.5vl:3b

# Start backend
python -m uvicorn api.server:app --reload --port 8000

# Frontend (separate terminal)
cd frontend && npm install && npm run dev
```

Open http://localhost:5173 — landing page → Fan Lens or Commentator Dashboard.

## Architecture

```
Browser (React / Vite)
  Fan Lens Broadcast ──────────┐
  Commentator Dashboard ────────┤
  Notes Generation Hub ─────────┤
                                │ WebSocket /ws/live
                                │ SSE   /api/v1/commentary/prepare-notes
                                │ HTTP  /api/v1/frame/analyze
                                ▼
              FastAPI Backend  (api/server.py)
                    │
        ┌───────────┼───────────────────────┐
        │           │                       │
   LiveAgent    7-Agent Notes           VisionAgent
   + QAAgent    Pipeline                (Qwen2.5-VL)
        │           │                       │
        │    ┌──────┴───────┐         Streaming
        │    │ Round-Robin  │         Fallback
        │    │ 5 Sources    │         Chain (L1→L4)
        │    └──────────────┘
        │           │
        └─── LLM Backend (ollama / openai / vllm)
```

**Single WebSocket per session** — `ConnectionManager` in `api/server.py` handles fan-out to all tabs. Game state (score, minute, phase) is attached to every outbound message.

## Three Views

### Fan Lens Broadcast

Cinematic full-viewport video with overlaid UI elements:
- **Scoreboard pill** (top center) — live score + match minute from `GameState`
- **Trivia cards** (bottom left) — auto-surfaced from `NotesStore` on vision events
- **Broadcast Engine** (bottom) — bias / excitement / knowledge sliders, language toggle (EN|ES)
- **Mic button** — hold to record voice query → Qwen2-Audio transcription → LLM answer → split-screen display

### Commentator Dashboard

- **60/40 split** — video left, teleprompter right
- **Teleprompter** — narrative beats rendered with 5 opacity tiers (past → current → future); current beat highlighted in Gold on vision detection
- **Beat highlighting** — `pitchai:beat_highlight` CustomEvent connects vision detections to teleprompter

### Notes Generation Hub

- Enter home + away team → SSE stream shows agent progress in real time
- Output: structured markdown with player profiles, tactical analysis, historical context, H2H records, weather, current news
- Takes 60–120s depending on LLM backend and data source speed

## 7-Agent Notes Pipeline

```
Round 1 (sequential)
  └── initialize_workflow()  →  ESPN squad + fixture fetch

Round 2 (parallel, asyncio.gather)
  ├── gather_initial_context()
  │     ├── NewsAgent
  │     ├── WeatherContextAgent
  │     └── HistoricalContextAgent
  └── research_squads()
        └── PlayerResearchAgent

Round 3 (parallel)
  ├── TeamFormAgent
  └── MatchupAnalysisAgent

Round 4 (sequential)
  └── NoteOrganizer  →  synthesizes all research into narrative beats
```

Each agent extends `BaseAgent` and calls `call_llm()` via `httpx.AsyncClient` — fully async, no event loop blocking.

## Vision Pipeline — 4-Level Fallback

The `/ws/video/streaming` endpoint runs a hardware-adaptive fallback chain:

| Level | Backend | Hardware needed | Status |
|---|---|---|---|
| 1 | StreamingVLM (MIT HAN Lab) | AMD MI300X / H100 (40GB+ VRAM) | Code ready, requires high-end GPU |
| 2 | SGLang KV sliding window | Any GPU + SGLang server | Code complete — activate with `SGLANG_BASE_URL` |
| 3 | Pre-computed embeddings | — | Not implemented, falls through |
| 4 | vLLM frame-by-frame | Consumer GPU (6GB+) | **Active default path** |

Level 4 tested on NVIDIA RTX 5060 8GB with `Qwen2.5-VL-3B-Instruct-AWQ`:
- ~2.5s latency per 5-second video chunk
- 6.2GB VRAM

To activate Level 2 (SGLang), set `SGLANG_BASE_URL` — no code changes needed.

```python
# Auto-selects highest available level
from streaming.factory import FallbackStreamingBackend
backend = FallbackStreamingBackend(use_fallback_chain=True)
await backend.initialize()
result = await backend.process_chunk(chunk)
```

## Data Sources

5-source round-robin with per-source rate limiting:

| Source | Auth | Rate limit | Best for |
|---|---|---|---|
| ESPN | None | 120 req/min | Squad sheets, fixtures, form |
| FootballData.org | `FOOTBALL_DATA_API_KEY` | 10 req/min | H2H, standings, top scorers |
| Transfermarkt | Scraped | 20 req/min | Player market values, profiles |
| OneVersusOne | `ONEVERSUSONE_API_KEY` | 15 req/min | 1v1 Index, progressive carries, pre-assists |
| Firecrawl | `FIRECRAWL_API_KEY` | 30 req/min | Current news, live form |

**StatsBomb** is available for historical research only — free catalog covers La Liga 2004–2021, UCL, World Cup, and Bundesliga 2023/24. Returns empty for current-season queries.

All retrieved data includes a `"data_source"` field so agents know which source responded.

## LLM Backends

Set `LLM_BACKEND` in `.env`:

| Backend | Use case | Models |
|---|---|---|
| `ollama` | Local development (free) | `qwen2.5:3b`, `qwen2.5vl:3b` |
| `openai` | Cloud fallback | `gpt-4o-mini` |
| `vllm` | Self-hosted, best quality | `Qwen2.5-VL-7B-Instruct-AWQ` |

Override per-component:
```env
COMMENTARY_NOTES_LLM_BACKEND=vllm   # notes pipeline only
VISION_LLM_BACKEND=vllm             # vision agents only
```

**Start vLLM (vision model):**
```bash
vllm serve Qwen/Qwen2.5-VL-3B-Instruct-AWQ \
  --host 0.0.0.0 --port 8001 \
  --trust-remote-code \
  --quantization awq_marlin \
  --gpu-memory-utilization 0.75
```

**Start SGLang (Level 2 vision, optional):**
```bash
python -m sglang.launch_server \
  --model-path Qwen/Qwen2.5-VL-7B-Instruct-AWQ \
  --host 0.0.0.0 --port 30000 --tp 1
```

**Voice transcription (Qwen2-Audio):**
```bash
vllm serve Qwen/Qwen2-Audio-7B-Instruct \
  --host 0.0.0.0 --port 8001
```
```env
AUDIO_VLLM_BASE_URL=http://localhost:8001
AUDIO_MODEL=Qwen/Qwen2-Audio-7B-Instruct
```

## WebSocket Protocol

All real-time state flows through a single WebSocket at `/ws/live`.

**Client → Server:**

| Message type | Fields | Description |
|---|---|---|
| `init` | `home_team`, `away_team`, `sport` | Start session |
| `settings_update` | `bias`, `excitement`, `knowledge_depth` | Commentary personalization |
| `language_switch` | `language` (`"en"` \| `"es"`) | Toggle commentary language |
| `match_event` | `description` | Manual event input (goal, card, sub) |
| `tactical_detection` | `analysis` | Vision detection forwarded to commentary |
| `query` | `text`, `confidence` | Voice/text Q&A |

**Server → Client:**

| Message type | Fields | Description |
|---|---|---|
| `ready` | `session_id` | Session initialized |
| `status` | `workflow_id` | Pre-match research starting |
| `commentary` | `text`, `beat_indices`, `gameState` | Live commentary generated |
| `trivia_card` | `text`, `source`, `display_duration_ms` | Trivia card to surface |
| `beat_highlight` | `beat_index`, `confidence` | Teleprompter beat to highlight |
| `answer` | `answer`, `overlay_coordinates` | Q&A response |
| `error` | `message` | Session error |
