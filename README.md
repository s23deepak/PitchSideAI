# 🏟️ PitchAI — Your AI Broadcast Companion

> **Real-time AI-powered football commentary with live tactical vision, contextual Q&A, and cross-language translation.**

PitchAI transforms how fans experience football by providing Peter Drury-style commentary notes, automatic trivia cards, voice-activated Q&A, and split-screen tactical analysis — all synced to the live match.

## ⚡ Quick Start

### Try the Demo (No Setup Required)

Visit our [Hugging Face Space](https://huggingface.co/spaces/deepu/PitchAI) or run locally:

```bash
# Clone and setup
git clone https://github.com/deepu/PitchAI.git
cd PitchAI
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cd frontend && npm install && npm run dev
cd .. && python -m uvicorn api.server:app --reload --port 8080
```

### Demo Experience

1. **Open** http://localhost:5173
2. **Click** "Start Watching" or select a sample match (Roma vs Napoli)
3. **Watch** for trivia cards to appear within 30 seconds
4. **Hold** the mic button to ask a question
5. **Explore** settings: language toggle (EN|ES), bias, excitement, knowledge depth

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎙️ **Live Commentary Notes** | Peter Drury-style narrative beats generated by 7-agent pipeline |

| 🎯 **Trivia Cards** | Auto-surfaced insights keyed to match events (goals, cards, subs) |

| ⚙️ **Personalization** | Sliders for team bias, excitement level, tactical knowledge depth |
| 📊 **Teleprompter** | Commentator dashboard with auto-scrolling narrative beats |

## 📊 Data Sources

PitchAI uses a **3-layer fallback chain** for statistics:

1. **StatsBomb** — Historical exact-match (TTL 4h, returns empty if season not in free catalog)
2. **Firecrawl** — Current-season primary (requires `FIRECRAWL_API_KEY`)
3. **FBref Direct** — Soccerdata last resort (may 403 in some environments)

All returned data includes `"data_source"` field for transparency.

### Sport-Specific Retrievers

| Retriever | Sport | Data Points |
|-----------|-------|-------------|
| `GoalComRetriever` | Football | xG, formations, lineups, shots |
| `CricbuzzRetriever` | Cricket | Strike rates, innings, bowling figures |
| `ESPNRetriever` | Basketball/Hockey/Baseball | Scores, stats, play-by-play |

## 🔌 LLM Backend Options

Set `LLM_BACKEND` in `.env` to switch providers:

| Backend | Use Case | Models | Cost |
|---------|----------|--------|------|
| `bedrock` | Production | Nova Pro/Lite/Sonic | Pay-per-token |
| `vllm` | Self-hosted | Qwen2.5-VL-7B-AWQ | GPU cost |
| `ollama` | Local dev | qwen2.5:3b, qwen2.5vl:3b | Free |
| `openai` | Cloud fallback | gpt-4o-mini | Pay-per-token |

### Recommended Configurations

**Production (AWS Bedrock):**
```env
LLM_BACKEND=bedrock
AWS_REGION=us-east-1
AWS_ACCESS_KEY_ID=xxx
AWS_SECRET_ACCESS_KEY=xxx
```

**Self-Hosted (vLLM on MI300X):**
```bash
vllm serve Qwen/Qwen2.5-VL-7B-Instruct-AWQ \
  --host 0.0.0.0 --port 8000 \
  --trust-remote-code \
  --quantization awq_marlin \
  --gpu-memory-utilization 0.75
```
```env
LLM_BACKEND=vllm
VLLM_BASE_URL=http://localhost:8000
VLLM_VISION_MODEL=Qwen/Qwen2.5-VL-7B-Instruct-AWQ
```

**Local Dev (Ollama):**
```bash
ollama pull qwen2.5:3b
ollama pull qwen2.5vl:3b
```
```env
LLM_BACKEND=ollama
OLLAMA_MODEL=qwen2.5:3b
OLLAMA_VISION_MODEL=qwen2.5vl:3b
```

## 🚀 Deployment

### Hugging Face Spaces (Docker)

PitchAI deploys as a single Docker container:

```bash
# Build and push
docker build -t deepu/pitchai:latest .
docker push deepu/pitchai:latest

# Deploy to HF Space (set VLLM_BASE_URL secret)
# Space auto-deploys from Docker Hub
```

### Environment Secrets

| Secret | Description |
|--------|-------------|
| `VLLM_BASE_URL` | GPU inference endpoint (e.g., `http://mi300x:8000`) |
| `AWS_ACCESS_KEY_ID` | Bedrock access (if using `bedrock` backend) |
| `AWS_SECRET_ACCESS_KEY` | Bedrock secret (if using `bedrock` backend) |
| `FIRECRAWL_API_KEY` | Live stats scraping (optional) |

### Memory Budgets

| Component | Target | Notes |
|-----------|--------|-------|
| HF Space RAM | < 12GB | Before model loading |
| MI300X VRAM | < 60GB | Qwen2.5-VL-7B + KV cache + agents |
| KV Cache | 120s retention | Temporal context for Q&A |

## 🎬 Demo Flow

### Self-Guided Mode (Community Visitors)

1. **Landing Page** → Click "Start Watching" or select match
2. **Video Plays** → Sample Roma vs Napoli match starts immediately
3. **First Visit Overlay** → 4-second greeting (auto-dismisses, never shown again)
4. **Trivia Cards** → First card fades in within 30 seconds
5. **Suggested Questions** → Tap a chip to see Q&A with split-screen
6. **Voice Q&A** → Hold mic button, ask a question, watch split-screen answer
7. **Settings** → Adjust bias, excitement, knowledge depth, language

### Narrated Demo (Live Demo Window)

Same flow, but with a narrator guiding each feature trigger.
